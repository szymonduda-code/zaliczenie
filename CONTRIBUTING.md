# Contributing

## Nazewnictwo branchy

Format:

zwierze-imie

Przykład:

tygrys-szymon

## Commity

Commity powinny być krótkie i opisywać wprowadzone zmiany.

Przykłady:

- Dodano zdjęcie tygrysa
- Dodano sekcję o tygrysie

## Pull Request

Każdy Pull Request powinien zawierać:

- opis zmian
- informacje o dodanym zwierzęciu
- listę zmodyfikowanych plików

## Komunikacja

Wszelkie uwagi należy zgłaszać poprzez GitHub Pull Requests lub Issues.
